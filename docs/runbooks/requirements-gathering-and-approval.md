# Runbook: Gathering requirements and getting approval
1. Book a discovery call with the owner. Use `docs/BRD.md` section 4 as the question list.
2. Ask for: business goal, audience, products, channels, budget, time zone, languages, brand words to use and avoid, which channels may run automatically.
3. Record each answer as Confirmed or Assumption in the BRD. Never mix them.
4. Send the BRD for review. List every open assumption in the email.
5. Collect written approval (name, date) in the BRD approval table.
6. Only then baseline the BRD (tag `brd-v1.0` in Git). Later changes go through a change request.
